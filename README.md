# clipforge

Режет длинные видео (подкасты, интервью, стримы) на вертикальные клипы 9:16 для TikTok / Reels / Shorts.
Работает локально на видеокарте NVIDIA с 8 ГБ видеопамяти.

```
видео / ссылка
  → транскрипция с таймкодами слов (faster-whisper)
  → поиск вирусных моментов локальной LLM (Qwen3 через llama.cpp) + сигнал громкости
  → переоценка лучших кандидатов
  → детекция лиц и склеек, плавная виртуальная камера 9:16
  → субтитры по словам с подсветкой
  → рендер на NVENC
```

## Установка (Windows 10/11)

Нужны: свежий драйвер NVIDIA, ~30 ГБ на диске, 32 ГБ ОЗУ.

### 1. Python, ffmpeg, git

В PowerShell:

```powershell
winget install Python.Python.3.11
winget install Gyan.FFmpeg
winget install Git.Git
```

Закройте и заново откройте терминал, чтобы обновился PATH.

### 2. Проект и зависимости

Скопируйте папку `clipforge` на компьютер (например, в `C:\clipforge`) и дважды щёлкните **`install.bat`**.
Он создаст виртуальное окружение, поставит зависимости (несколько ГБ, в том числе CUDA-библиотеки для Whisper,
так что CUDA Toolkit отдельно не нужен), создаст `config.yaml` и ярлык **clipforge** на рабочем столе.

<details><summary>То же самое вручную</summary>

```powershell
cd C:\clipforge
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy config.example.yaml config.yaml
```
</details>

### 3. llama.cpp (сервер для LLM)

1. Откройте https://github.com/ggml-org/llama.cpp/releases и скачайте из последнего релиза два архива под Windows с **cuda** в названии:
   сам llama.cpp (`llama-*-bin-win-cuda-*-x64.zip`) и `cudart-llama-bin-win-cuda-*-x64.zip`.
2. Распакуйте оба в одну папку, например `C:\llama`. Там должен лежать `llama-server.exe`.

### 4. Модель

Скачайте GGUF-файл с Hugging Face в `C:\models`:

- **Основная:** Qwen3-30B-A3B-Instruct-2507, квантование `Q4_K_M` (~18 ГБ), например из репозитория
  `unsloth/Qwen3-30B-A3B-Instruct-2507-GGUF`. Это MoE-модель: эксперты лежат в ОЗУ, остальное на видеокарте.
- **Быстрая для отладки:** Qwen3-8B `Q4_K_M` (~5 ГБ), полностью в видеопамяти.
  В настройках поставьте «Слоёв экспертов в ОЗУ» = 0.

Если к моменту установки вышли более новые версии этих моделей, берите их.

### 5. Первый запуск

1. Откройте ярлык **clipforge** на рабочем столе (или `clipforge.bat`).
2. Вкладка **Настройки** → укажите путь к `llama-server.exe` и к файлу модели `.gguf` → **Сохранить настройки**.
3. Нажмите **Проверить окружение**. Везде должны быть зелёные галочки. Если нет, под каждым пунктом написано, что сделать.

## Работа в программе

1. Вкладка **Клипы**: перетащите видео в окно, нажмите «Выбрать видео…» или вставьте ссылку на YouTube.
2. Выберите количество клипов, длину, язык и нажмите **Создать клипы**.
   Внизу видны текущий этап, прогресс и журнал. Кнопка **Стоп** прерывает обработку после текущего шага.
3. Готовые клипы появятся в списке, отсортированные по оценке. Щелчок по клипу запускает его во встроенном плеере,
   справа показано, почему модель его выбрала.
4. **Перерендерить** — пересобрать клипы проекта после смены стиля субтитров или кадрирования (без повторного распознавания и LLM).
   **Найти моменты заново** — снова спросить LLM (например, после смены модели или длины клипов).
   **Открыть папку** — папка с готовыми mp4.

Все прошлые проекты доступны в списке «Проект».

## Командная строка

То же самое без интерфейса:

```powershell
.venv\Scripts\activate
python -m clipforge run "D:\videos\podcast.mp4"
python -m clipforge run "https://www.youtube.com/watch?v=..." -n 5
python -m clipforge doctor
```

При первом запуске скачаются модель Whisper (~1.6 ГБ) и детектор лиц (~300 КБ).

Результат в `work\<имя видео>\`:

| Файл | Что внутри |
|---|---|
| `clips\01_*.mp4` … | готовые вертикальные клипы, отсортированы по оценке |
| `report.md` | для каждого клипа: заголовок, оценки, почему выбран, текст |
| `clips.json` | таймкоды и оценки. Можно поправить руками и перерендерить |
| `transcript.json` | слова с таймкодами и предложения |
| `llm_server.log` | лог llama.cpp, если что-то пошло не так |

Каждый этап кэшируется. Повторный запуск пропускает готовое. Переделать этап:

```powershell
python -m clipforge run video.mp4 --force highlights   # заново спросить LLM
python -m clipforge run video.mp4 --force render       # перерендерить (например, после смены стиля субтитров)
python -m clipforge run video.mp4 --force all
```

## Настройка

- **Скорость LLM.** Во время поиска моментов посмотрите `nvidia-smi`. Если видеопамять занята не полностью,
  уменьшайте «Слоёв экспертов в ОЗУ» (`n_cpu_moe`: 48 → 40 → 32…): часть экспертов переедет на видеокарту, генерация ускорится.
  Если llama.cpp падает с нехваткой памяти, увеличьте обратно или уменьшите контекст.
- **Язык.** `whisper.language: ru` убирает автоопределение. Если `large-v3-turbo` ошибается, поставьте `large-v3`.
- **Длина клипов:** `highlights.min_duration` / `max_duration`.
- **Субтитры:** шрифт, размер, цвета, количество слов на экране в секции `captions`.
- **Облачная LLM вместо локальной:** в настройках выберите «Внешний сервер» и укажите адрес, ключ и имя модели
  любого OpenAI-совместимого API.
- Всё, чего нет в интерфейсе (пороги склеек, мёртвая зона камеры и т. д.), настраивается в `config.yaml`.
  Значения по умолчанию описаны в `clipforge/config.py`.

## Как выбирается кадр

- Видео декодируется с частотой 8 кадров/с, лица ищет детектор YuNet (OpenCV).
- Склейки находятся по изменению цвета и картинки и уточняются до точного кадра. На склейке камера переключается мгновенно.
- Внутри одной сцены лица связываются в треки. Камера следит за самым заметным лицом. Если лицо почти не двигается,
  камера стоит неподвижно. Если двигается, камера плавно доезжает до него с ограничением скорости.
- Если два человека помещаются в вертикальный кадр, в кадр берутся оба.

## Ограничения MVP и что дальше

- Камера выбирает самое крупное и стабильное лицо, а не обязательно того, кто сейчас говорит.
  Следующий шаг: определение говорящего (TalkNet / LR-ASD) и разделение по спикерам (pyannote).
- Нет split-screen (два говорящих друг над другом), когда люди не помещаются в один кадр.
- Модель видит только текст и громкость. Визуальные моменты без слов (реакции, действия) она пропустит.
- Нет заголовка-хука поверх видео, эмодзи, B-roll.
